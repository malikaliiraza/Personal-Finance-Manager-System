# Personal-Finance-Manager-System


A C++ console-based Personal Finance Manager built using Object-Oriented Programming (OOP) principles to manage personal financial records efficiently. It allows users to track income, expenses, account balance, schedule meetings, and generate daily and monthly financial reports. The project demonstrates the implementation of inheritance, polymorphism, encapsulation, abstraction, and STL containers in a real-world application. Designed with a clean, menu-driven interface for an organized and user-friendly experience.
