# Personal-Finance-Manager-System


A C++ console-based Personal Finance Manager built using Object-Oriented Programming (OOP) principles to manage personal financial records efficiently. It allows users to track income, expenses, account balance, schedule meetings, and generate daily and monthly financial reports. The project demonstrates the implementation of inheritance, polymorphism, encapsulation, abstraction, and STL containers in a real-world application. Designed with a clean, menu-driven interface for an organized and user-friendly experience.

---

## 📖 Overview

The **Personal Finance Manager** is a C++ console application developed using **Object-Oriented Programming (OOP)** principles to simplify personal financial management. The system enables users to record income and expenses, monitor their account balance, schedule meetings, and generate daily and monthly financial reports. Built with a modular class-based architecture and STL containers, the project demonstrates practical implementation of core OOP concepts, including inheritance, polymorphism, encapsulation, and abstraction, while providing an interactive, menu-driven user experience.

---

## ✨ Features

* 🔐 Password-protected user authentication
* 💵 Add and manage income records
* 💸 Record and track expenses
* 💰 View real-time account balance
* 📜 Display complete transaction history
* 📅 Schedule and manage meetings
* 📊 Generate daily financial reports
* 📈 Generate monthly financial reports
* 📉 Automatic profit and loss calculation
* ⚠️ Prevents overspending by validating available balance
* 🧩 Modular OOP-based architecture using classes and inheritance
* 📚 Utilizes C++ STL (`vector` and `map`) for efficient data management

## Getting Started

### Prerequisites
- Microsoft Visual Studio, **or** any C++ compiler (g++, clang++, etc.)

### Installation

```bash
git clone https://github.com/malikaliiraza/Personal-Finance-Manager-System-.git
cd Personal-Finance-Manager-System-
```

**Option A — Visual Studio**
Open the project folder in Visual Studio and run the application (Ctrl+F5).

**Option B — Command line (g++)**
```bash
g++ Source.cpp -o Personal-Finance-Manager-System-
./Personal-Finance-Manager-System-
```
